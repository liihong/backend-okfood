> 只改界面。不改接口、字段、下单、支付、地址、券的逻辑。  
> 气质对齐管理端 `VISUAL-DIRECTION-IOS-GLASS.md` 和 `COLOR-PRIMARY-CANDIDATES.md`。页面结构不要套 `ADMIN-UI-DIALOG-LIST-SPEC.md`。

## 1. 范围

改用户能走到的页面：4 个 Tab（首页、点单、订单、我的）以及 `packageOrder`、`packageUser`。

配送员 `pages/courier/`、骑手 `pages/rider/` 这次不动。

公共样式抽到一处，页面里不要再各写一套颜色和圆角。现有品牌绿 `#73B054` 只留在还没改到的页面上，改过的页面改用下面的 token。

## 2. 色和形状

| Token | 用途 | 值 |
|---|---|---|
| 画布 | 页面底 | `#F7FAFB` |
| 实底 | 列表、表单、菜单、确认页、地址 | `#FFFFFF` |
| 界面色 | 按钮、价格、图标、选中 | 黑 `#1D1F21`、白、冷灰。不另铺装饰色 |
| 主文 | 标题、正文 | `#1D1F21` |
| 辅文 | 说明、未选中 | `#5C6670` |
| 分割 | 细线 | `rgba(0, 0, 0, 0.06)` |
| 玻璃 | 导航、Tab、首页主卡 | `rgba(255, 255, 255, 0.86)`，模糊约 14px |

界面保持干净明亮。按钮、价格、加号、图标格、选中态用黑白灰，不给每块再上一种颜色。饱和色只来自照片和卡面本身（餐品图、会员卡原有的绿和橙）。

圆角收着：卡片和按钮 **12px**，输入框 **10px**。只有底部 Tab 用胶囊。不要把加号、分段、图标格都做成全圆。内层控件圆角 ≈ 外层圆角减去内边距。

间距走 **8px** 网格。阴影只一层、模糊大、透明度低。玻璃上的字用深色实色，不写半透明字。

语义色（成功、警告、错误）只在状态字上用一小块，价格用黑色。

## 3. 已定稿（预览 `preview-redesign-glass.html`）

对照页是首页「爆炒三鲜配杂粮饭」和点单「本周」。下面四条按那一版写死。

1. **顶部图**：首页和本周各一张大图，顶到内容区上沿。颜色来自照片，界面不再给图染色。
2. **页面卡片**：图下压一张玻璃信息卡。首页卡里是日期、菜名、一行价格、一行剩余次数（「11月12日 周四 午餐 / 爆炒三鲜配杂粮饭 / 微辣 · ¥30 / 晚餐月卡 · 还剩 24 次」）。玻璃约六成白，背后模糊，顶上一条高光，字用深色。
3. **本周午餐、晚餐下面的图**：星期和午晚餐是字，不是左边一列分类。下面只放当天这一张餐图，再写菜名和配料。不要做成美团那种左分类、右列表。
4. **Tab**：只出现在四个 Tab 页（首页、点单、订单、我的）。悬浮胶囊，离安全区留出空隙，左右不贴边。选中项是胶囊里一块更白的底，字是深色；未选中是灰色字。不要贴底白条，也不要做成带图标的系统底栏。

**详情页不放 Tab。** 菜品详情、确认下单、地址、请假、卡包、券、消费记录，只有返回和本页内容。

## 4. 壳层

微信没有系统液态玻璃。`backdrop-filter` 在 iOS 微信上可用，安卓经常没有，还会掉帧。玻璃只做高不透明度薄层，并准备一层同位置的实色白底。不要整页铺模糊。

玻璃只放三处：

1. **导航** `OkNavbar`：停在顶部时是实色白底；页面向下滚动后，才叠一层薄玻璃。返回、标题、品牌字保持现在的位置和点击行为。
2. **Tab** `custom-tab-bar`：见上一节。四个入口仍是首页、点单、订单、我的。详情页不挂这层。
3. **首页信息卡**：见上一节，压在顶部图上。其余密内容页用白底。

按钮：主操作是深色字加浅底或细边，圆角 12px。不要再做一块实心绿。

菜单、确认页、地址、券、卡包这些密内容页用白底或极浅实底，不铺玻璃。

## 5. 改的顺序

1. 公共 token 和壳：导航、Tab、按钮、卡片。
2. 四个 Tab。
3. 下单链路（零售确认、商城确认）。
4. 账户链路（地址、请假、卡包、券、抖音核销）。

每一批只换皮：布局、字段、接口不动。需要重排某一页时单独说。

## 6. 不要做

- 不改 API 字段和业务分支。
- 不把后台的表头、侧栏、面包屑、弹窗规范搬进小程序。
- 不整页 `backdrop-filter`。
- 不先改配送员和骑手页。
- 不在每个页面里复制一套颜色变量。
