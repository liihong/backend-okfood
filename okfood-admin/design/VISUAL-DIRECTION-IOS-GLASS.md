## 1. 从「你喜欢的图标气质」抽象出什么

你偏好的图标近似：**软体量、柔光、分层、少量渐变、可选磨砂层**（玻璃压在内容之上），而不是硬朗金融风或彩虹数据墙。

倒推到整站时，建议把它们落成 **三条可执行原则**：

1. **空气感**：大块浅色底、柔和色光（mesh），用留白分块，而不是用深墙色或重边框堆层次。  
2. **材质分级**：**全站只有少数层级**使用强毛玻璃（顶栏、侧边条顶区、1～2 张「主 KPI」卡）；表格与表单以 **高可读** 的实色/极浅实色为主。  
3. **多巴胺点缀、正文要稳**：侧栏/空状态可用「**每个入口一种柔和水果色**」+ **玻璃方底 + 内联 SVG**（软 3D 径向渐变 + 高光），营造愉悦感；但 **表格、表单、图表** 仍用 **低饱和主色系 + 同色相阶梯**，避免整站变成高饱和贴纸风。**导航选中态**建议 **实色底 + 白字 + 轻阴影**；水果色只佔 **左侧小图标区域**，不铺满内容区。

## 2. 「iOS 毛玻璃」在 Web / Element Plus 里怎么理解

- **不是什么**：不是把整个页面每一块卡都 `blur(50px)`，也不是到处是强半透明字（伤对比、累眼）。  
- **是什么**：  
  - 底层：极浅的 **冷白/米白** + **极淡的多色渐变光斑**（仅氛围）。  
  - 中层：**悬浮导航条、侧边顶区、个别强调卡** 使用 `backdrop-filter: blur() saturate()` + 半透明白 + 细亮边，模拟 **vibrancy**。  
  - 上层：正文与表格保持 **清晰实色背景**（可极浅灰），保证长时间阅读。

技术上对应关系（实现时再细化）：`backdrop-filter`、`background: rgba(255,255,255,0.42~0.72)`、`border: 1px solid rgba(255,255,255,0.55)`、`box-shadow` 极低不透明。

## 3. 色板方向（比上一版更浅、更「空气」）

以下为 **讨论用 Hex**（偏「更亮、选中更显眼、少雾感」一版；预览页已同步），仍可在源码里微调。

| Token | 用途 | 参考 Hex |
|--------|------|-----------|
| `bg-canvas` | 全页底色（略提亮） | `#F7FAFB` |
| `mesh-a` / `mesh-b` | 背景色光（随主色三套略变，预览页已写） | 见预览 CSS 中 `[data-theme="primary-mojito"` / `iris` / `peach`]` |
| `surface-solid` | 表格区、密列表容器 | `#FFFFFF` 或 `#F9FAFB` |
| `glass-fill` / `glass-fill-strong` | 毛玻璃填充（更不糊：提高 α、blur≈14px） | `rgba(255,255,255,0.70)` / `rgba(255,255,255,0.86)` |
| `primary` | 主按钮、**侧栏选中实底** | **蜜桃珊瑚（默认）** `#E8927C` · **莫吉托** `#5CBF8E` · **雾紫** `#8B7EC8`（预览页下拉切换） |
| `primary-hover` | 悬停 | `#DD7F68` · `#4AB37E` · `#7A6DB8`（对应上表） |
| `nav-active-text` | 选中项文字 | `#FFFFFF`（与实色底对比） |
| `text-primary` | 主文 | `#1D1F21`（可略浅于纯黑） |
| `text-secondary` | 辅助说明 | `#5C6670` |
| `border-hairline` | 极细分割 | `rgba(0,0,0,0.06)` |

语义色（成功/警告/错误）仍建议 **降饱和、小面积**，与 iOS 的系统色思路一致。

## 4. 组件层级策略（避免「玻璃糊成一团」）

| 区域 | 建议材质 | 说明 |
|------|----------|------|
| 全局背景 | 纯色 + 2～3 个模糊色光 | 提供 depth，不抢内容 |
| 顶栏 / 侧栏顶 Brand | **毛玻璃** | 固定态，用户常看，易建立品牌感 |
| 侧栏菜单 · 当前页 | **实色主色条 + 白字**（或左缘 3～4px 指示条） | 避免「浅底灰字」导致当前位置不显眼 |
| 侧栏 · 每项左侧图标 | **多巴胺水果 SVG**（每模块不同色相：蓝紫 / 深红 / 玫红 / 黄 / 品紫 / 青绿 / 翠绿 / 橙 / 珊瑚橙 / 靛紫；对应水果：蓝莓 / 石榴 / 樱桃 / 香蕉 / 火龙果 / 梨 / 苹果 / 橘子 / 杨梅 / 山竹；预览页为内联 SVG） | 真 3D 资产可后续换 **WebP**；**玻璃方底色与 SVG 渐变按色相环岔开**，避免侧栏成片粉红/大红；规则是「**彩只在小格子里**」，不与 KPI 彩虹条混用 |
| KPI 主卡（最多 1～2 张） | **毛玻璃或淡渐变玻璃** | 对标「图标里的焦点层」 |
| 其余 KPI、筛选条 | 白实色 + 轻阴影或仅边框 | 保持干净 |
| 表格、表单、校验 | **尽量实底** | 密度高，对比优先 |
| 表格 · 行选中 | **浅主色底 + 整行外阴影微抬升**，避免在每个 `td` 上用 `inset` 左边条（易产生列间竖线） | 预览页 `pickup-table` 已示意；落码时可用 `ElTable` 的 `row-class-name` + 自定义阴影 |
| 顶栏 · 下拉 / Popper | **整条顶栏**需建立高于主内容区的堆叠顺序 | 若顶栏与主内容区为**同级兄弟**且主内容在 DOM 后，未设 `z-index` 时整块正文会盖住顶栏内的用户下拉（子元素 `z-index` 只在父级层内比较）。预览页用 `.top { position: relative; z-index: 40 }` + `.shell { z-index: 0 }`；正式用 `ElDropdown` 时注意 `popper-class` 或布局顺序。 |

### 壳层布局（顶栏、面包屑、侧栏与用户）

以下为 **后台高频路径** 的推荐摆位；预览 `okfood-admin-theme-preview-ios-glass.html` 中已用 **可展开侧栏分组 + 子导航** 做静态示意（非完整路由，仅看层级与选中态）；**账号 / 时间 / 通知**已在预览顶栏右侧成组展示，可与你的产品稿对照微调间距。

| 区域 | 建议 | 说明 |
|------|------|------|
| **面包屑** | 放在 **主内容区顶部、左对齐**（顶栏内第一行或顶栏正下方一行小号字） | 表达「整站在哪」：如 `首页 / 经营概况 / 数据汇总`；**当前页用字重或主色**，前级用次要灰；避免单独一个胶囊只表达一级。正式可用 Element Plus `ElBreadcrumb`。 |
| **页面标题** | 紧挨面包屑 **下方**（或同块内第二行），左对齐 | 面包屑是层级，标题是当前页一句话；**主次操作（导出 / 保存等）放在主内容区标题行右侧**，预览顶栏壳层仅保留通知 / 时间 / 用户，不重复放说明文案与操作按钮。 |
| **当前用户 / 退出** | **顶栏右侧**（与通知同一行或紧邻），侧栏只保留导航 | 预览页为<strong>点击用户条</strong>展开菜单：<strong>主题色</strong>、<strong>系统设置</strong>、<strong>退出</strong>为同一层级；再点<strong>主题色</strong>展开三色（蜜桃珊瑚 / 莫吉托 / 雾紫，默认蜜桃珊瑚并写入本地）。正式可用 `ElDropdown` + `ElDropdownMenu` 子菜单等价实现。 |
| **实时时钟** | **可选** | 需要首屏感知时段时放在顶栏（预览为**本地时间**、每秒刷新）；不需要可去掉，改在日志列或详情展示。 |
| **侧栏 · 一级 + 子页** | 有一组子路由时：**一级可点击展开/收起**；**二级为纯文字列表**（无圆点、无「小胶囊描边」），**选中**用主色字 + 极淡主色底即可，左侧可用细竖线与一级对齐 | 父级在子选中时可保留 **弱高亮**（字重），避免双「满饱和」条抢焦点。预览里「营业概览 / 订单管理」等下含示例子页，可点选看左侧变化。 |
| **侧栏 · 一级文案（与 OK 饭健康餐参考稿对齐）** | 预览页一级菜单为 **10 项**：营业概览、会员档案、开卡工单、订单管理、配送管理、数据统计、菜单管理、库存管理、小程序营销、系统管理 | 与「会员制经营系统」壳并列；每项配 **一种水果 SVG**：蓝莓、石榴、樱桃、香蕉、火龙果、梨、苹果、橘子、杨梅、山竹（**色相在环上拉开**，如樱桃偏玫红、火龙果偏品紫、梨偏青绿、苹果偏翠绿、杨梅偏珊瑚橙），随主色切换仍可辨。 |

**反馈与加载（与蜜桃珊瑚 / 玻璃一致）**

- **全局加载**：页顶极细条 + 主色流动高光（预览 `#demo-global-loading`）；正式可用 `ElLoading.service` 全屏或路由条。
- **操作结果**：**视口顶部居中**毛玻璃轻条，成功 / 失败 / 信息三类色相（预览 `#demo-toast-stack`）；正式统一走项目里的 **`showToast`**（建议 `placement: 'top'` / 等价配置）或 `ElNotification`，勿用 `window.alert`。
| 空状态 / 运营插画 | 轻 3D / 柔边插画 | 与图标语言一致，不占高频路径 |

## 5. 形状、字号、间距（与 iOS 接近的「柔和」）

- **圆角**：组件统一用两档即可 —— **16px**（常规）、**22～24px**（大卡片/导航条圆角容器）。  
- **阴影**：单层、大模糊、低不透明（避免 Neumorphism 双层腻感）。  
- **字号**：延续后台可读性 —— KPI 可大，但表格正文不小于 13–14px 等效。  
- **间距**：仍以 **8px 网格**，毛玻璃区域 **内边距略大**（更「松弛」）。

---

## 6. 和「轻质感 3D 图标」的衔接

- **导航图标**：预览页侧栏已用 **小尺寸内联 SVG**（径向渐变模拟软 3D）；正式落地时可抽成 **Sprite 或单文件组件**，并与 Element Plus 线性图标并存于「点缀区」。
- **品牌关键时刻**：首页问候、空状态、品类入口使用 **与你参考图同源的软 3D/插画**，形成记忆点。  
- **图标配色**：从 `primary` + `mesh` 紫蓝里取 **1～2 个高光色**，与界面 token 对齐，避免图标与 UI 两套色。

---

## 7. 风险与约束（落地上要提前说好）

- **对比度**：毛玻璃上文字必须用 **深色实色** 或 **加一层极淡实底**，避免 WCAG 翻车。  
- **性能**：大范围 `backdrop-filter` 在弱设备上可能掉帧 —— **限定在顶栏/少量卡片**。  
- **Element Plus**：表格/弹窗需单独调玻璃或回退为实色，否则默认样式与玻璃叠在一起易脏。

## 8. 下一步怎么定稿

1. 打开 `okfood-admin-theme-preview-ios-glass.html`，看 **背景 + 顶栏玻璃 + KPI 玻璃** 是否接近你想要的「iOS 感」。  
2. 反馈三个点即可：**主色再亮一点还是再柔一点？**、**毛玻璃 blur（例如 14px → 10px）？**、**侧栏选中要「全宽实底」还是「左侧彩条 + 浅底」？**  
3. 定稿后把 token 映射到 `--el-color-primary`、`--el-bg-color`、以及少量自定义「玻璃」工具类，再进页面级替换。
