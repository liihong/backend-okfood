OK 轻食门店后台 · 视觉方向（讨论稿）

方向：清晰、低饱和、大留白；图表用同一绿色相的明度阶梯，避免金融感霓虹与彩虹条。可与 Element Plus 的 CSS 变量对齐后落地。

和「最新设计语言」对齐怎么说？
近年产品后台常见共识是：内容优先、少装饰（弱玻璃/弱拟物）、Bento 分区但克制圆角与阴影、类型与密度可切换、图表语义色固定。轻食品牌更适合有机绿 + 暖灰底，少用冷紫/电青渐变。本页即「看得见」的 token + 局部组件样式参考。
